## Supported Versions

The following distributions have been tested and are officially supported for EMInstaller:

| Distro    | Version | Status      |
| --------- | ------- | ----------- |
| Archlinux | Latest  | ✓ |
| Manjaro | Latest  | ~ |
| EndeavourOS | Latest  | ~ |


- ✓ Supported
- ~ Untested
- x Not supported


### Testing on Other Distributions

If you have successfully tested EMInstaller on other Arch-Linux-based distributions, please open a discussion with:
- Distribution name and version
- Screenshots of the installation process
- Notes on any features that work or don't work

## Reporting a Vulnerability

If you discover a security vulnerability in EMInstaller, please report it responsibly. **Do not** open a public issue; instead, contact me privately:

- **Discord**: imemix
- **Reddit**: imemixx (note: two x's)

### What to Include

When reporting a vulnerability, please provide:
- Description of the vulnerability
- Steps to reproduce the issue
- Potential impact
- Suggested fix (if available)

All vulnerability reports are taken seriously and will be addressed promptly.
